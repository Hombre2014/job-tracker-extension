## Tips for Great Screenshots

### 1. Use Real Data

- Use actual job postings (blur personal info if needed)
- Show realistic salary ranges
- Use recognizable company names (if allowed)

### 2. Keep It Clean

- Close unnecessary browser tabs
- Use a clean browser profile (no clutter)
- Disable other extensions in screenshots
- Use default browser theme or professional dark theme

### 3. Highlight Key Features

- Use arrows or highlights to draw attention
- Show the extension icon clearly
- Zoom in on important UI elements
- Ensure text is readable

### 4. Consistency

- Use same browser zoom level for all screenshots
- Maintain consistent UI theme (light or dark)
- Same window size across screenshots
- Professional and cohesive look

### 5. Quality

- Save as high-quality PNG
- Don't over-compress
- Ensure sharp text (no blur)
- Check colors look good on both light/dark backgrounds

## Optimization

After creating screenshots/GIFs:

### Images

```bash
# TinyPNG (online): https://tinypng.com
# ImageOptim (Mac): https://imageoptim.com
# FileOptimizer (Windows): https://sourceforge.net/projects/nikkhokkho

# Or use command line:
# For PNG: optipng -o7 screenshot.png
# For JPG: jpegoptim --max=85 screenshot.jpg
```

### GIFs

```bash
# Gifsicle (command line):
# gifsicle -O3 --lossy=80 -o output.gif input.gif

# ezgif.com (online): https://ezgif.com/optimize
# Reduce colors, resize if needed
```
